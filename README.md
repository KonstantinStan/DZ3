# Домашнее задание 3

## Задание 1. Мониторинг
Здесь настроен простой стек мониторинга в Docker:
- **Node Exporter** собирает метрики с виртуальной машины
- **Prometheus** опрашивает exporter и следит за его статусом (цель в статусе UP)
- **Grafana** выводит всё это на красивый дашборд с графиками загрузки процессора, памяти, диска и сети

## Задание 2. Docker для counter-backend
Для бэкенда написаны три разных Dockerfile, чтобы сравнить подход к сборке:
1. **single** — обычная сборка в один этап, приложение запускается от root
2. **multistage** — многоступенчатая сборка: сначала собираем зависимости в отдельном контейнере, а в финальный образ кладем только код и готовые пакеты
3. **nonroot** — то же самое, что multistage, но приложение работает от имени обычного пользователя `appuser` ради безопасности, а не от root 

Все контейнеры проверены через `curl` — эндпоинты `/api/counter` отлично отдают и обновляют данные.
